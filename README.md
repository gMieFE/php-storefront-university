# PHP Storefront

A simple online storefront developed as a university project using PHP and SQL.

## Technologies

* PHP
* SQL
* HTML
* CSS

## Features

* Product management
* Database integration
* Online storefront interface

## Setup

1. Clone the repository.
2. Import `DB.sql` into your database.
3. Configure the database connection.
4. Run the project using a local PHP server.

## Purpose

This project was created to gain practical experience in PHP development, databases, and building web applications.
